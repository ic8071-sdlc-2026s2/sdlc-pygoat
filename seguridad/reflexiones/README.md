# Reflexiones individuales

Cada integrante copia `plantilla.md` a `<su-usuario-de-github>.md`, por ejemplo `mfernandez.md`, y la completa. Una sección por sesión, sobre el rol que lideró en esa sesión.

El commit debe salir de su propia cuenta: el verificador compara el nombre del archivo con el autor de los commits. Una reflexión subida por otra persona no cuenta.

Vale 30 % de la nota del laboratorio. La califica el profesor con la rúbrica.
